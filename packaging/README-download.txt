TWINWISE - make a safe twin of your spreadsheets before you use AI
Everything runs on this computer. Nothing is uploaded.

WINDOWS
  Double-click Twinwise.exe. Your browser opens the app.
  If Windows says "Windows protected your PC": click More info -> Run anyway
  (the app is not code-signed yet).

macOS (Apple Silicon)
  Double-click "Start Twinwise.command".
  If macOS says it cannot verify the developer:
    System Settings -> Privacy & Security -> scroll down -> "Open Anyway",
  or right-click the file -> Open -> Open.

LINUX
  Run ./start-twinwise.sh  (or ./Twinwise ui)

Keep the small terminal window open while you work; close it to stop Twinwise.
Your library (templates, names, safe words) is saved in the .twinwise folder
in your home directory. Twins are saved in Twinwise/exports in your home folder.

User guide and source code: https://github.com/Chalkduggo/Twinwise
